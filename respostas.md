1. O que é um repositório?
Um repositório é o local onde ficam armazenados os arquivos de um projeto e o histórico das alterações realizadas nele.

2. Qual a diferença entre Git e GitHub?
O Git é uma ferramenta utilizada para controlar as versões e alterações de um projeto. O GitHub é uma plataforma na internet onde podemos armazenar, compartilhar e trabalhar com projetos que utilizam Git.

3. Para que serve um commit?
Um commit serve para registrar e salvar uma alteração feita no projeto. Ele permite acompanhar o histórico do desenvolvimento.

4. Por que utilizamos branches?
Utilizamos branches para desenvolver novas funcionalidades ou fazer alterações separadamente, sem modificar diretamente a branch principal (main).

5. Qual a finalidade de um Pull Request?
O Pull Request serve para solicitar a revisão das alterações feitas em uma branch antes de juntá-las à branch principal (main).

6. Qual a diferença entre fazer um commit e fazer um push?
O commit registra uma alteração no histórico do projeto. O push envia essas alterações para o repositório no GitHub.

7. O que acontece quando um Pull Request é realizado?
Quando um Pull Request é realizado, as alterações feitas na branch são apresentadas para revisão. Depois da revisão e aprovação, elas podem ser juntadas à branch principal por meio do merge.

8. Qual a finalidade do merge?
O merge serve para juntar as alterações de uma branch com outra, normalmente juntando as alterações da branch de desenvolvimento com a main.

9. Por que não é recomendado realizar todo o desenvolvimento diretamente na main?
Porque a main deve permanecer organizada e estável. Utilizando branches, podemos desenvolver novas funcionalidades separadamente e depois juntá-las à main quando estiverem prontas.
